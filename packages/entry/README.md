# @deepseek-ai/dsh-node-addon-internal

Published main package for `@deepseek-ai/dsh-node-addon-internal`.

It exports the JavaScript API, selects a native binary through
`@deepseek-ai/dsh-node-addon-internal-loader`, and falls back to a local N-API build when
no current-platform optional package is usable.

See the repository [README](../../README.md) for usage and support status.
